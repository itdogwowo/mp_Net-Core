## 2. 現在的行為（定案）

### 2.1 節點清單的顏色 = **關係狀態**，不是時間

| 顏色 | 意義 | 什麼時候變 |
|---|---|---|
| 🟢 綠 | 我認的目標（在 `@node.targets`）| 按「綁定」|
| 🟡 琥珀 | 這次掃描有回（`age_ms <= since`）| 按「掃描」|
| 🔴 紅 | **掃描過了，它沒回** | 按「掃描」後約 0.5 秒 |
| ⚪ 灰 | 還沒按過掃描（我還沒問過）| 開機 |

**選中那一列**：淺藍底 `SEL_BG=0xD2E3FC` + **永遠保留狀態色**。

> ★ 為什麼不是漸層：`age` 變大只代表「對端沒再講話」，**不代表它離線**。
> 舊版「按掃描→綠→幾秒後自己變琥珀→再變紅」讓使用者困惑（我又沒做什麼）。

### 2.2 週期公告已關（兩台 Test_Peer）

`ports/S3/ESP32-S3-Test_Peer/Core_Manager.py`
```python
ANNOUNCE_EVERY_MS = 0      # 0 = 只廣播一次（開機那次）
```
⚠️ **不能只改數字** —— 舊判斷式 `ticks_diff(...) < ANNOUNCE_EVERY_MS` 在 0 時
恆為 False → **每一圈都廣播**。已補上 `elif self._last: return`。

### 2.3 `0x100D` 的兩種模式 + 狀態機

| `reply_cid` | 模式 | 行為 |
|---|---|---|
| 具體 cid | 定向點名（**面板用這個**）| **每次都回** |
| `0xFFFF` | 廣播回覆 | 同一個問的人**只回第一次** |
| `+ force=1` | 強制 | 忽略紀錄，重回 |

狀態的鍵是**問的人的 MAC**（不是 bool）—— 否則「第二台較晚開機的遙控器
永遠收不到回覆」（＝使用者說的「我開機不等於他開機」）。只記最近 4 人。
